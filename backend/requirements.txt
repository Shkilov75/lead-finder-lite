# The real list is the repository root's requirements.txt. This file only
# includes it, so `pip install -r requirements.txt` from inside backend/
# installs exactly what Vercel installs — one source of truth, so a dependency
# added for local dev cannot go missing in production.
#
# Don't invert this by moving the pins back here and pointing the root file at
# them. Vercel's Python runtime parses the root requirements.txt itself and
# rejects `-r`, so the root has to hold the literal pins; pip, which reads this
# file, resolves `-r` relative to the file it appears in and is happy with it.
-r ../requirements.txt
